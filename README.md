# 大模型推理引擎

一份面向实习岗位的系统性教材，覆盖推理引擎内核、推理服务与平台、模型部署与性能调优三个方向。

- 建立时间：2026-08-10
- 关联材料：`~/self/aisys-learning/`。其中 `05-推理系统.md` 是本教材的浓缩版，读完本教材后不需要再读那一篇。
- 设计文档：`docs/superpowers/specs/2026-08-10-推理引擎教材-design.md`

---

## 每章的结构

| 段 | 内容 |
|---|---|
| 1 | 问题是什么 |
| 2 | 机制怎么工作 |
| 3 | 主流引擎的实现对照 |
| 4 | 本机可运行的验证代码 |

代码位于 `code/`，命名为 `chNN_<名称>.py`，直接运行即可：

```bash
python3 code/ch02_roofline.py
```

依赖：Python 3.9+、numpy、torch（CPU 即可）。第 17、18、20 章为源码导读、引擎对照与面试问答，没有配套代码。

正文中的全部数据表都由这些脚本生成，修改脚本顶部的常量即可复现或换成你自己的模型与硬件。

## 使用说明

- 正文中的硬件数值（带宽、算力、显存容量）用于建立量级概念，具体型号以厂商文档为准。
- 本机无 NVIDIA GPU，涉及真实 kernel 性能、张量并行、PD 分离的结论均标注为「未在本机验证」。这类结论在面试中应说明来源。
- 引擎的具体接口与文件路径变动较快，以官方文档与当时的代码为准。正文中给出的路径基于 2026 年年中的版本。
- 标注「原因未查明」的条目表示没有确认，不要作为结论陈述。
