## 1. 目标

为一名有系统方向背景（RDMA 数据面、调度控制面、LLM Agent 后端）但缺少推理引擎知识的读者，提供一份可以支撑推理方向实习面试与实际工作的系统性教材。

覆盖三类岗位的要求：

| 岗位类型 | 教材中的对应章节 |
|---|---|
| 推理引擎内核研发 | 02-14、17 |
| 推理服务与平台 | 15、16、19 |
| 模型部署与性能调优 | 05、13、19 |

主线为引擎内核，服务化与调优作为后续章节。

## 2. 约束

| 项 | 内容 |
|---|---|
| 硬件 | 仅本机 Mac，无 NVIDIA GPU |
| 运行环境 | Python 3.9.6，numpy 2.0.2，torch 2.8.0 |
| 代码定位 | 每章配一个独立可运行脚本，用于验证正文中的量化结论 |
| 语言 | 中文，遵循 `~/.claude/CLAUDE.md` 的写作规范 |

无 GPU 带来的限制：张量并行、PD 分离、真实 kernel 性能只能停留在原理与计算层，正文中需明确标注哪些结论未在本机验证。

## 5. 代码规范

- 仅依赖 Python 标准库、numpy、torch（CPU）
- 兼容 Python 3.9：不使用 `X | Y` 联合类型语法
- 每个脚本可直接 `python3 code/chNN_xxx.py` 运行，输出自带说明
- 脚本中的模型参数（层数、头数、维度）集中在文件顶部常量区，便于修改后重算

## 6. 不做的内容

- 训练侧的并行与优化（属于 `aisys-learning/04`）
- 模型结构本身的设计与预训练
- 具体厂商 GPU 型号的参数手册复制
- 无法在本机验证且无公开数据支撑的性能数字
